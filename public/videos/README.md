# Video nền Q-Dcom

Thêm hai tệp MP4 riêng để dùng video nền độc lập cho từng giao diện:

- Đăng nhập/đăng ký: `login-bg-video.mp4` (đường dẫn `/videos/login-bg-video.mp4`).
- Dashboard/ứng dụng: `app-bg-video.mp4` (đường dẫn `/videos/app-bg-video.mp4`).

Nếu chưa thêm tệp, nền đồ họa tĩnh vẫn hiển thị và mọi chức năng ứng dụng tiếp tục hoạt động.
